# Оценка Data Encryption at Rest and In Transit

## Что нужно сделать

- Определить, какие данные нужно защитить. 
- Реализовать базовые инструменты защиты.
- Использовать автоматизированный контроль. 
- Подготовить реестр программных и аппаратных средств для защиты данных.

## Средства контроля за данными (реестр стредств защиты)

### Database Activity Monitoring (DAM)

Реализуется при помощи pgAudit, который позволяет отслеживать, кто, что и когда сделал с данными в каждой из таблиц; фиксирует действия, выполняемые администраторами.

### API Activity Monitoring

Делается средствами Kong.

### Role-Based Access Control (RBAC)

Реализуется при помощи Keycloak.

### Контроль утечек данных

Здесь можно применить различные DLP, например -- InfoWatch Traffic Monitor.
